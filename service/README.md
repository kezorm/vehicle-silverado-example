## Adding an entry

Add a row above, newest last. For anything with paperwork, create a dated
subfolder (`service/2026-09-15-lifters/`), put the invoice and photos there, and
link it in the Records column.

**Transcribe the whole invoice, not the parts that changed something.** See the
note on line item 5 in the inspection invoice for why.

For self-performed work, record the parts and fluids actually used — that detail
is what makes [`reference/fluids-and-parts.md`](../reference/fluids-and-parts.md)
trustworthy over time.

## Measurements are the real payload

An invoice that says "brakes good" is worthless in three years. A table of pad
thicknesses is a baseline you can subtract from — it converts the next
inspection from an opinion into a wear rate. Whenever a shop has the wheels off,
ask for numbers and file them.
