# Vehicle Data Plates and Stickers

> **⚠️ FABRICATED.** No such vehicle exists. These transcriptions demonstrate
> *format and practice*, not any real truck's build. Read your own labels.

Photographs of the physical labels, transcribed below so the data is searchable
without opening the images. In a real record the `.jpg` files sit beside this
file; they are omitted here because a certification label carries the VIN.

---

## Why this file is the clearest case for archival capture

**Almost nothing on this page is actionable, and that is the point.**

The rear axle ratio changes nothing this week. It is the first thing a parts
counter asks when you need a differential rebuild kit in 2034. The GAWR figures
matter the one time you tow something heavy. The paint code matters the one time
a fender gets scratched.

A data plate is a document that exists *once*, physically, on a vehicle that
will eventually be sold or scrapped. **The transcription outlives the label.**
Photograph it, then transcribe it — a photo nobody has transcribed is not a
record, it is a to-do, and it is not greppable.

**Transcribe the whole plate.** Not the two fields that matter today. You have
the label open and your attention on it exactly once.

## Service Parts Identification (RPO) Label

Usually inside the glovebox lid or the centre console on GM trucks. **This is
the single most valuable archival label on a GM vehicle** and the one most
often ignored, because at a glance it is meaningless — a block of three-
character option codes.

> **What it is for.** GM builds the same model in thousands of configurations.
> The RPO list is the authoritative statement of *which one this is*. When a
> parts catalogue asks "which rear axle / which transfer case / which seat
> trim," this label answers it and nothing else does. Once the truck is sold,
> the label goes with it.

| RPO | Meaning |
|---|---|
| `L83` | 5.3L EcoTec3 V8, Active Fuel Management |
| `MYC` | 8L90 8-speed automatic transmission |
| `NQH` | Two-speed transfer case, electronic |
| `G80` | Locking rear differential |
| `Z71` | Off-road suspension package |
| `GT4` | 3.42 rear axle ratio |
| `LT` | Trim level |

> **`[verify]`** — this list is **illustrative of format**, assembled to show
> what an RPO block looks like and why it is worth transcribing. It is not a
> decoded real vehicle. On a real truck, transcribe **every** code on the
> label, including the ones you cannot decode: an undecoded code is still a
> fact, and the decoder tables improve over time.

**Transcribe unknowns verbatim.** The temptation is to record only the codes
you could look up. The ones you could not are exactly the ones a specialist
will want.

## Still worth photographing

- [ ] Tire sidewalls — DOT date codes, to establish tire age independently of
      any service record
- [ ] Battery label — group size, type, date sticker
- [ ] Any underhood or door-jamb notes left by previous owners

> **Why that last one matters.** In the record this method came from, a strip of
> tape under the hood reading "PLUGS 81K" was the *only* evidence that the spark
> plugs had ever been changed — it appeared in no service history anywhere. A
> previous owner's marker pen closed a gap that a paid vehicle history report
> could not.
